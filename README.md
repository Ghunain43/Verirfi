# Verifi
Slow rumors down without reading anyone's chats.

Code//Connect '26 - Problem 03: Misinformation Control. Team: Bug Beaters.

## Structure
- `backend/`   FastAPI: scope gate, research, sources, evidence, privacy, security
- `extension/` Chrome extension (Manifest V3)
- `mobile/`    Flutter app with Share target
- `web/`       Next.js: results, rumor radar, admin view
- `shared/`    API schema and fingerprint spec used by all clients
- `docs/`      Threat model, architecture, pitch
